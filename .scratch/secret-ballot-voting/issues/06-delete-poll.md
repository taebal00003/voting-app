# 06: 운영자가 투표를 삭제한다

**What to build:** 운영자가 확인 창을 거쳐 투표를 삭제하면, 그 투표의 선택지, 결과, 참여 기록이 영구히 사라지고 운영자와 투표자 목록에서 모두 없어진다. 삭제된 투표를 보고 있던 투표자에게는 "삭제된 투표예요" 안내와 목록으로 돌아가는 버튼이 나온다. 동작은 이미 구현되어 있으므로, 이 티켓은 테스트로 고정한다. 스펙: 사용자 스토리 20, 59.

**Blocked by:** 03, 04

**Status:** resolved

- [x] 다음 동작을 테스트한다.
  - 투표자가 투표한 투표를 삭제하면, 투표 조회는 없음을 돌려줌
  - 운영자 목록과 투표자 목록에서 사라짐
  - 그 투표의 참여 기록이 더는 참여 현황이나 "투표 완료" 표시에 나오지 않음
  - 삭제된 투표에 투표하면 `gone`
  - 다른 투표의 선택지와 결과에는 영향이 없음
  - 없는 ID나 잘못된 형식의 ID로 삭제해도 오류가 나지 않음
- [x] 테스트 준비에 필요한 투표는 도메인 모듈의 공개 인터페이스(투표하기)로 만든다. DB에 직접 넣지 않는다.
- [x] 타입 검사, lint, 빌드, 테스트가 통과한다.
