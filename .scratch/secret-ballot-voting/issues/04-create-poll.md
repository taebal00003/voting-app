# 04: 운영자가 투표를 만든다

**What to build:** 운영자가 제목과 선택지 2~10개로 투표를 만들면, 운영자 목록에 참여 0명으로 나타나고 투표자 목록에도 최신순으로 나타난다. 입력 검증을 도메인 모듈 안으로 옮겨서, 투표 만들기가 원시 입력(제목, 선택지 칸들)을 받아 스스로 검증하게 하고, 이 여정을 테스트로 고정한다. 스펙: 사용자 스토리 10, 12, 48~55.

**Blocked by:** 01

**Status:** resolved

- [x] 투표 만들기는 원시 제목과 선택지 칸들을 받는다. 사용자에게 보여줄 오류 문구, 또는 새 투표 ID를 돌려준다. Server Action은 결과를 전달만 한다.
- [x] 운영자 화면의 동작은 지금과 같다. 오류가 나도 입력값이 남고, 성공하면 그 투표의 관리 화면으로 간다.
- [x] 다음 동작을 테스트한다.
  - 제목과 선택지의 앞뒤 공백 정리, 빈 선택지 칸 무시
  - 제목이 비었거나 100자를 넘으면 거부
  - 선택지가 2개 미만이거나 10개 초과면 거부, 50자 초과면 거부, 같은 문구가 있으면 거부
  - 입력한 선택지 순서 보존, 새 투표의 표 수는 모두 0
  - 운영자 목록에서 새 투표가 맨 앞에 참여 0명으로 나옴
  - 투표자 목록에 최신순으로 나오고 "투표 완료"가 아님
- [x] 용어는 CONTEXT.md를 따른다. 투표가 묻는 문장은 "질문"이 아니라 "제목"이다.
- [x] 타입 검사, lint, 빌드, 테스트가 통과한다.
