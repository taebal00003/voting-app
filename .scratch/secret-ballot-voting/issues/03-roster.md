# 03: 운영자가 투표자 명부를 관리한다

**What to build:** 운영자가 이름을 붙여 넣어 투표자를 한 번에 등록하면 투표 코드가 발급된다. 운영자는 코드를 재발급하거나 투표자를 명부에서 뺄 수 있고, 투표자는 받은 코드를 대충 입력해도 입장할 수 있다. 입력 검증과 코드 정규화를 도메인 모듈 안으로 옮겨서 호출하는 쪽은 검증을 따로 하지 않게 하고, 이 여정을 테스트로 고정한다. 스펙: 사용자 스토리 1~7, 36~47. 결정 기록 0001을 따른다.

**Blocked by:** 01

**Status:** resolved

- [x] 코드 조회는 원시 입력을 받아 대문자로 바꾸고 공백·하이픈을 제거한 뒤 찾는다.
- [x] 운영자 명부 화면과 투표자 코드 입력 화면의 동작과 안내 문구는 지금과 같다.
- [x] 다음 동작을 테스트한다.
  - 여러 명 한 번에 등록
  - 코드 형식: 헷갈리는 글자를 뺀 8자리
  - 명부에 이미 있는 이름이 섞이면 아무도 등록되지 않고 그 이름이 반환됨
  - 입력 안의 중복 이름, 20자 초과, 빈 입력 거부
  - 소문자·공백·하이픈이 섞인 코드로도 조회됨
  - 재발급하면 이전 코드는 조회되지 않음
  - 명부에서 빼면 코드가 조회되지 않음
  - 뺀 이름은 다시 등록할 수 있음
  - 명부 목록은 이름순이고, 뺀 투표자는 목록에 없음
