# 스펙: 모든 화면에 만든 사람 이름 표시

Status: ready-for-agent

## Problem Statement

이 앱을 누가 만들었는지 화면 어디에도 나오지 않는다. 동아리 회장의 부탁을 받아 앱을 만든 사람(권태현)은 투표자와 운영자가 앱을 쓰면서 만든 사람을 알 수 있기를 바란다. 문의할 사람을 찾을 때도 도움이 된다.

## Solution

앱의 모든 화면 하단에 "만든 사람: 권태현"이 작게 표시된다. 코드 입력 화면, 투표 목록, 투표 화면, 운영자 로그인과 운영자 화면 모두 해당한다.

## User Stories

1. 투표자로서, 코드 입력 화면 하단에서 이 앱을 만든 사람의 이름을 보고 싶다. 그래야 믿고 코드를 입력할 수 있다.
2. 투표자로서, 투표 목록과 투표 화면, 결과 화면 하단에서도 만든 사람의 이름을 보고 싶다.
3. 운영자로서, 운영자 로그인 화면과 모든 운영자 화면 하단에서 만든 사람의 이름을 보고 싶다.
4. 투표자로서, 삭제된 투표 안내 화면처럼 예외적인 화면에서도 같은 위치에 이름이 보이길 바란다. 그래야 앱이 일관되게 보인다.
5. 투표자로서, 이름 표시가 투표 버튼이나 결과를 가리지 않고, 휴대폰 화면에서 본문보다 눈에 덜 띄길 바란다.
6. 스크린 리더 사용자로서, 이름이 본문과 구분된 하단 정보로 읽히길 바란다.

## Implementation Decisions

- 이름은 루트 레이아웃 하나에 둔다. 그러면 모든 화면에 자동으로 나오고, 이후 추가될 화면도 따로 챙길 필요가 없다.
- 하단은 `footer` 요소로 두고, 본문보다 작고 옅은 글자로 표시한다. 문구는 "만든 사람: 권태현"이다.
- 이름은 고정 문구로 둔다. 환경변수나 설정으로 빼지 않는다(바뀔 일이 드물고, 필요해지면 그때 뺀다).
- 도메인 모듈, 데이터, 스키마는 바뀌지 않는다.

## Testing Decisions

- 도메인 동작이 없어서 도메인 모듈 경계에서는 테스트하지 않는다. 새 테스트 경계도 만들지 않는다.
- 운영 빌드를 띄워 대표 화면(코드 입력 화면, 운영자 로그인 화면)의 HTTP 응답에 문구가 들어 있는지 확인하고, 휴대폰 폭에서 본문을 가리지 않는지 눈으로 확인한다.
- 선례: 운영자 경로 가드(`secret-ballot-voting` 티켓 02)도 운영 빌드와 HTTP 요청으로 확인했다.

## Out of Scope

- 연락처, 링크, 버전 표시
- 이름을 설정으로 바꾸는 기능
- 마감 시각과 결과 그래프(`.scratch/poll-closing-time/spec.md`에서 다룸)

## Further Notes

- `.scratch/poll-closing-time/spec.md`의 Out of Scope에는 "화면에 만든 사람 이름 표시 (표시할 이름이 정해지지 않음)"가 있다. 이름이 권태현으로 정해져서 이 스펙으로 따로 다룬다.
- 레이아웃만 건드리므로 마감 시각 작업과 파일이 겹치지 않는다.
