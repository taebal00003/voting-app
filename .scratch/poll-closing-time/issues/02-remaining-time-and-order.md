# 02: 남은 시간을 보여주고, 마감이 가까운 투표를 위로 올린다

**What to build:** 투표자 목록, 운영자 목록, 투표 화면에 남은 시간을 보여준다. 예: "마감까지 5시간". 24시간 안이면 강조한다. 목록 순서는 다음과 같다.
1. 진행 중이면서 마감이 있는 투표: 마감이 가까운 순
2. 진행 중이면서 마감이 없는 투표: 최신순
3. 마감된 투표: "마감됨" 표시, 최근에 마감된 순

스펙: 스토리 5~7, 11.

**Blocked by:** 01

**Status:** resolved

- [x] 남은 시간 표시 순수 함수를 만든다.
  - 입력은 마감 시각과 기준 시각이다.
  - 문구는 N일 / N시간 / N분 / 곧 마감이다.
  - 24시간 이내인지 여부도 돌려준다.
  - 서버와 브라우저 양쪽에서 쓸 수 있다.
- [x] 투표자 목록과 운영자 목록이 위의 세 구간 순서로 나온다.
- [x] 목록과 투표 화면에 남은 시간이나 "마감됨"이 보이고, 24시간 이내면 강조된다.
- [x] 테스트: 문구 단위별 경계, 24시간 경계, 두 목록의 세 구간 순서
- [x] 타입 검사, lint, 빌드, 전체 테스트가 통과한다.
