# 01: 운영자가 마감 시각을 정하고, 마감되면 투표가 막힌다

**What to build:** 운영자가 투표를 만들 때 마감 시각을 선택적으로 정할 수 있게 한다.
- 마감 시각이 지나면 서버가 투표를 거부한다.
- 투표 화면은 버튼을 비활성화하고 "마감된 투표예요" 안내를 보여준다.
- 마감된 투표의 결과는 명부의 모든 투표자에게 보인다.

스펙: `.scratch/poll-closing-time/spec.md`, 스토리 1~4, 8~10.

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [x] `polls.closes_at`이 추가되고, 기존 투표는 마감 없음으로 남는다. 스키마 적용은 여러 번 실행해도 안전하다.
- [x] 투표 만들기가 원시 마감 시각을 받는다.
  - 빈 값이면 마감 없음이다.
  - 값은 한국 시간으로 해석한다.
  - 과거나 형식 오류면 오류 문구를 돌려준다.
- [x] 마감 후 투표하면 `closed`를 돌려주고, 참여 기록과 결과는 변하지 않는다. 판정은 DB 시각 기준이다.
- [x] 투표 조회가 마감 시각과 마감 여부를 돌려준다.
- [x] 운영자 새 투표 폼에 마감 시각 입력 칸(비어 있음)이 있다.
- [x] 투표 화면:
  - 마감되면 선택지와 버튼이 비활성화되고 안내가 나온다.
  - 참여하지 않았어도 결과가 보인다.
  - 마감 뒤에 제출하면 `closed` 안내가 나온다. (도메인 테스트와 화면 렌더로 확인. 브라우저에서 "열어둔 채 마감 지나 제출"은 사람이 확인할 것)
- [x] 테스트: KST 해석, 비움, 과거·형식 오류 거부, 마감 전 `ok`, 마감 후 `closed`와 결과 불변, 마감 여부 조회
- [x] 타입 검사, lint, 빌드, 전체 테스트가 통과한다.
