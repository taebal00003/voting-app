# 03: 결과를 비율 막대그래프로 보여준다

**What to build:** 결과 화면을 선택지별 가로 막대그래프로 다듬는다. 막대 길이는 비율이고, 선택지마다 명수와 %를, 그래프 위에 총 투표수를 보여준다. 1위를 강조하고, 동률이면 모두 강조한다. 휴대폰 세로 화면에서 긴 선택지 이름도 읽을 수 있고, 스크린 리더로도 결과를 알 수 있어야 한다.

스펙: 스토리 12~13.

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [x] 투표자 결과 화면과 운영자 결과 화면이 같은 그래프를 쓴다.
- [x] 총 투표수, 선택지별 명수와 %, 1위(동률 포함) 강조, 0표일 때 0%
- [ ] 긴 선택지 이름은 줄바꿈되고, 명수·%와 겹치지 않는다. (마크업상으로는 겹치지 않음. 휴대폰 화면에서 사람이 확인할 것)
- [x] 스크린 리더가 각 막대를 "선택지 이름, N명, P%"로 읽는다.
- [x] 빌드가 통과하고, HTTP 응답으로 그래프 마크업을 확인한다.
