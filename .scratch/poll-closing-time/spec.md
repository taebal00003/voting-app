# 스펙: 마감 시각과 결과 그래프

Status: ready-for-agent

## Problem Statement

동아리 회장의 말: "투표가 계속 열려 있어서 사람들이 참여를 안 한다." 지금은 투표에 끝이 없어서, 투표자는 참여를 미루고, 운영자는 결과를 언제 확정할지 정할 수 없다. 결과 화면도 선택지별 비교가 한눈에 들어오도록 그래프로 보여줄 필요가 있다.

## Solution

- 운영자는 투표를 만들 때 **마감 시각**을 선택적으로 정한다. 마감 시각이 지나면 그 투표는 **마감됨**이 된다.
- 마감된 투표에서는 투표 버튼이 비활성화되고 안내가 보인다. 결과는 명부의 모든 투표자에게 공개된다.
- 목록과 투표 화면에 남은 시간이 보이고, 마감이 가까운 투표가 목록 위로 올라온다.
- 결과는 선택지별 비율 막대그래프와 총 투표수로 보여준다.

## User Stories

1. 운영자로서, 투표를 만들 때 마감 시각(날짜와 시:분, 한국 시간)을 정하고 싶다. 그래야 참여 기한을 줄 수 있다.
2. 운영자로서, 마감 시각을 비워두고 투표를 만들 수도 있길 바란다. 그러면 지금처럼 삭제될 때까지 진행된다.
3. 운영자로서, 과거 시각을 넣으면 "마감 시각은 지금 이후여야 해요" 안내를 받고 싶다.
4. 운영자로서, 마감 시각은 만든 뒤 바꿀 수 없길 바란다. 그래야 결과를 보고 마감을 늦춘다는 의심을 받지 않는다.
5. 투표자로서, 목록과 투표 화면에서 "마감까지 5시간"처럼 남은 시간을 보고 싶다.
6. 투표자로서, 마감이 24시간 안으로 다가온 투표가 눈에 띄게 표시되길 바란다.
7. 투표자로서, 목록에서 진행 중인 투표를 마감이 가까운 순으로 먼저 보고 싶다. 그 아래에 마감 없는 투표가 최신순으로, 맨 아래에 마감된 투표가 "마감됨"으로 나와야 한다.
8. 투표자로서, 마감된 투표를 열면 투표 버튼이 비활성화된 채 "마감된 투표예요" 안내를 보고 싶다. 버튼이 숨겨지면 안 된다.
9. 투표자로서, 투표하지 않았더라도 마감된 투표의 결과는 보고 싶다.
10. 투표자로서, 마감 직전에 화면을 열어두었다가 마감 뒤에 제출하면 거부되고 "마감된 투표예요" 안내를 받고 싶다.
11. 운영자로서, 운영자 목록에서도 각 투표가 진행 중인지 마감됐는지, 언제 마감되는지 보고 싶다.
12. 투표자와 운영자로서, 결과를 선택지별 비율 막대그래프와 총 투표수로 보고 싶다. 1위는 강조되어야 한다.
13. 투표자로서, 휴대폰 세로 화면에서 선택지 이름이 길어도 그래프를 읽을 수 있길 바란다.

## Implementation Decisions

- **용어**: CONTEXT.md의 마감 시각, 진행 중 / 마감됨, 결과 정의를 따른다.
- **스키마**: `polls`에 `closes_at timestamptz null` 열을 추가한다. 스키마 적용은 계속 여러 번 실행해도 안전해야 한다. 기존 투표는 null이며, 마감 없음을 뜻한다.
- **투표 만들기**: `createPoll(rawTitle, rawOptions, rawClosesAt)`
  - `rawClosesAt`은 입력 칸의 원시 값이다. 빈 값이면 마감 없음이다.
  - 값은 `YYYY-MM-DDTHH:mm` 또는 `YYYY-MM-DDTHH:mm:ss` 형식이고, 한국 시간(+09:00)으로 해석한다.
  - 형식이 틀렸거나 지금 이후가 아니면 오류 문구를 돌려준다.
  - 최대 기간 제한은 두지 않는다.
- **마감 판정은 서버가 DB 시각(`now()`)으로 한다.**
  - `castVote`는 마감된 투표에 대해 새 결과 `closed`를 돌려준다. 이때 참여 기록과 표 수는 바뀌지 않는다.
  - 기존의 한 SQL 문 원자성은 유지한다.
- **조회**: `getPoll`, `listPollsFor`, `listPollsForAdmin`이 마감 시각과 마감 여부를 함께 돌려준다. 마감 여부도 DB 시각 기준이다.
- **목록 순서**: 진행 중이면서 마감 있음(마감 가까운 순) → 진행 중이면서 마감 없음(최신순) → 마감됨(최근에 마감된 순).
- **결과 공개**: 참여했거나 마감됐으면 결과를 보여준다. 운영자는 항상 본다.
- **남은 시간 표시**: 순수 함수로 만든다. 입력은 마감 시각과 기준 시각이고, 출력은 다음과 같다.
  - 문구: "마감까지 N일", "N시간", "N분", 1분 미만이면 "곧 마감"
  - 24시간 이내인지 여부
  - 서버와 브라우저 양쪽에서 쓸 수 있어야 한다. 페이지를 렌더할 때 계산하고, 실시간 카운트다운은 하지 않는다.
- **그래프**: 선택지별 가로 막대를 쓴다. 막대 길이는 비율이다. 선택지마다 명수와 %를, 그래프 위에 총 투표수를 보여준다. 1위를 강조하고, 동률이면 모두 강조한다. 스크린 리더용 설명도 넣는다.

## Testing Decisions

- 테스트 경계는 기존과 같다. 도메인 모듈의 공개 함수만 대상으로 하고, 실제 테스트용 Neon 브랜치를 쓴다.
- 남은 시간 표시 함수는 도메인의 순수 함수로 보고 같은 경계에서 테스트한다. 기준 시각을 인자로 넘기므로 시계를 모킹하지 않는다.
- 다룰 동작:
  - 마감 시각 입력 해석(KST), 비움 허용, 과거와 형식 오류 거부
  - 마감 전 투표 `ok`, 마감 후 투표 `closed`이며 결과가 변하지 않음
  - 마감 여부 조회
  - 목록 순서 세 구간
  - 남은 시간 문구와 24시간 경계
- 마감을 지나게 하려면 몇 초 뒤를 마감 시각으로 만들고 기다린다. 초 단위 입력을 허용하는 이유가 이것이다.
- 화면(버튼 비활성화, 그래프)은 빌드와 HTTP 응답으로 확인한다.

## Out of Scope

- 마감 시각 수정, 일찍 마감하기
- 실시간 카운트다운, 마감 알림
- 복수 선택, 투표별 참여 대상
- 화면에 만든 사람 이름 표시 (표시할 이름이 정해지지 않음)
